Quick file actions and screen recording for Windows — hold a file, pick an action from the radial wheel or menu list, and let Halo handle the rest.

### What's new in 0.2.0

- **Redesigned recorder controls** — clearer settings with visual pickers for pointer style, click effects and highlights, plus a live cursor preview that shows your choices before you record.
- **Reliable window capture** — recording a window that isn't in front no longer hangs, and the source list shows window thumbnails.
- **Smarter audio** — if a microphone or system-audio device is unavailable, Halo records the video without it and switches the toggle off instead of failing.
- **Glowing click effect** with weak, moderate and strong intensity.
- **Steadier recorder window** — it stays centered as the toolbar grows or shrinks.
- **Branded installer** with a custom header and sidebar.
- **Refreshed README** and radial wheel screenshots.

See [CHANGELOG.md](https://github.com/ssanaullahrais/Halo/blob/master/CHANGELOG.md) for the full list and [README.md](https://github.com/ssanaullahrais/Halo#readme) for screenshots and optional engine setup.

Requires 64-bit Windows 10/11 and Microsoft Edge WebView2.

### Verifying downloads

Each installer ships with a `.sig` file and is listed in `SHA256SUMS.txt`. Installed copies of Halo verify `latest.json` and update downloads automatically using Halo's signing key before applying an update.
